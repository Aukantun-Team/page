# Recursos del rediseño

El fondo y la composición se construyen de forma nativa en HTML, CSS y SVG: cortes de papel, trama de puntos, líneas, estrellas y tipografía. Todos comparten el mismo sistema de color y movimiento.

| Archivo | Uso |
| --- | --- |
| `assets/aukantun-emblem.png` | Emblema original de AUKANTUN con transparencia, utilizado como figura central y favicon. |
| `assets/aukantun-wordmark.png` | Logotipo horizontal original con transparencia. El CSS lo presenta en blanco. |
| `assets/biotecard-logo.png` | Logo oficial de BioteCard, conservado sin modificaciones y mostrado completo sobre blanco. |
| `assets/menu-bold.otf` | Nimbus Sans Narrow Bold para títulos y comandos. |
| `assets/body-bold.otf` | Nimbus Sans Bold para textos y controles. |
| `assets/FONT-LICENSE.txt` | Licencia de las fuentes. |

Los logos se prepararon previamente con la herramienta integrada ImageGen a partir de los archivos del usuario. El rediseño conserva esos dos recursos. Ya no se utiliza ninguna de las ilustraciones generadas para los fondos anteriores.

Las instrucciones empleadas originalmente para preparar los logos fueron: quitar únicamente el fondo blanco y los huecos blancos a transparencia real; conservar las proporciones, contornos, formas y color morado del emblema; mantener el texto negro del logotipo horizontal sin alterar su tipografía. La presentación monocroma se aplica en CSS.
